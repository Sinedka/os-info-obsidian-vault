# Type and Attributes (IDT Gate)

## Что это такое
Поле Type/Attributes в записи IDT определяет тип шлюза, уровень привилегий и признак присутствия. От него зависит, как процессор обрабатывает прерывание и кому разрешено вызывать обработчик.

## Состав поля
Поле занимает 1 байт и имеет следующую структуру (бит 7 — старший):
- **P (Present)** — бит 7. Должен быть 1, иначе запись считается отсутствующей.
- **DPL (Descriptor Privilege Level)** — биты 5–6. Минимальный уровень привилегий, с которого разрешён вызов через `int`.
- **S** — бит 4. Всегда 0 для системных дескрипторов (IDT).
- **Type** — биты 0–3. Тип шлюза.

## Типы шлюзов (Type)
- **0xE** — 32/64‑битный Interrupt Gate. При входе процессор сбрасывает IF.
- **0xF** — 32/64‑битный Trap Gate. IF не сбрасывается.
- **0x5** — Task Gate (устаревший, через TSS, в современных ОС почти не используется).

## Примеры значений
- **0x8E** = 1000 1110b
  - P=1
  - DPL=0
  - S=0
  - Type=0xE (interrupt gate)
- **0xEE** = 1110 1110b
  - P=1
  - DPL=3
  - S=0
  - Type=0xE (interrupt gate)

## Практические замечания
- Для аппаратных прерываний и исключений обычно используют **interrupt gate** с DPL=0.
- Для системных вызовов может использоваться DPL=3, чтобы разрешить вызов из user mode.
- Если P=0, процессор генерирует исключение #NP при попытке вызвать такой вектор.
